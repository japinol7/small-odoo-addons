## We recommend installing the following OCA addons:

### 1. Web Environment Ribbon

* Technical name: 
  * web_environment_ribbon
* Version:
  * 19.0.1.0.0
* GitHub URL: 
  * https://github.com/OCA/web
  * https://github.com/OCA/web/tree/19.0/web_environment_ribbon
* Description:
  * Mark a Test Environment with a red ribbon on the top left corner in every page.
* Authors:
  * Francesco OpenCode Apruzzese
  * Tecnativa
* Contributors
  * Francesco Apruzzese <cescoap@gmail.com>

### 2. Web Dialog Size

#### Note: Still not available in Odoo 19.0.

* Technical name:
  * web_dialog_size
* Version:
  * 19.0.1.0.0
* GitHub URL:
  * https://github.com/OCA/web
  * https://github.com/OCA/web/tree/19.0/web_dialog_size
* Description:
  * A module that lets the user expand/restore the dialog box size through a button in the upper right corner.
    * It also adds draggable support to the dialogs.
* Authors: ACSONE SA/NV, Therp BV, Siddharth Bhalgami,Tecnativa, Amaris, Odoo Community Association (OCA).
